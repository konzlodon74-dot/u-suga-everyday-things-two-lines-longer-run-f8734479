# Everyday Things, Two Lines, Longer Run

A tiny Python program (standard library only, deterministic, no network, no randomness) that writes a two-line explanation of a toaster for a 10-year-old to `/output/entry.txt` and prints the same text. Line 1 explains the toaster through one concrete, surprising analogy — a tiny lift carrying bread down into a glowing-hot basement — and line 2 says honestly which parts of the toaster that analogy maps and which it leaves out.

## How to run

```sh
python3 main.py
```

## Entry text

> A toaster is a tiny lift that carries your bread down into a glowing-hot basement, browns both sides at once, and pops it back up when the timer dings.
> The lift explains the drop, the heat on both sides, and the pop-up, but it leaves out the red-hot wires that make the heat and why bread turns brown instead of just getting warm.

The entry text is 330 characters long (two lines, no trailing newline). The program prints exactly the same text it writes to the file.
